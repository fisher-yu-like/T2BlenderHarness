评分标准

当前评审对象：sample_a。请分别完整观看 sample_a / sample_b / sample_c 三个盲评视频。两名评分者必须使用不同 ID、独立完成评分，不要查看 plan、目录映射或隐藏实验信息。

分数锚点

0–10缺失或明显错误
25–45部分实现，关键证据不足
50–65基本完成但问题明显
70–85较好，只有局部问题
90–100几乎无明显问题且证据充分

评审原则

  • 视频中无法确认的事件不要根据 prompt 或 plan 猜测，降低分数并写明证据不足。
  • 重点观察镜头是否覆盖事件、人物和物体轨迹是否连续、事件顺序是否可读。
  • 不要因为是 proxy 自动给 0，也不要在缺少可见证据时给 100。
  • 确定性检查和几何检查由程序独立完成，人工只记录视频可见事实。
